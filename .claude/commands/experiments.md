description: Review, design, or read out experiments
---

Read `business/EXPERIMENT_LOG.md` and `business/data/experiments.json`.

Report running experiments with days elapsed, experiments ready to read out, and what each result
changes. Then either read out a finished experiment or design the next one.

Every experiment carries: ID, hypothesis, variable, control, test, cost, start date, end date,
result, decision. Success and failure criteria are set before it starts, never after.
