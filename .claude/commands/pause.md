description: Pause all autonomous work and checkpoint state
---

Stop current work. Write a checkpoint to `business/reports/CHECKPOINT-YYYY-MM-DD.md` containing:
what was in progress, what state each workspace file is in, what was about to happen next, and
anything time-sensitive that decays while paused (a prospect awaiting a reply, an experiment
mid-flight).

Commit the workspace so nothing is lost. Then stop and take no further autonomous action until the
founder resumes.
