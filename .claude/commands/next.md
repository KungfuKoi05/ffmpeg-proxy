description: Identify and execute the single highest-leverage next action
---

Read `business/MASTER_PLAN.md` (current bottleneck), `business/KPI_DASHBOARD.md`, and
`business/data/pipeline.json`.

Identify the **one** action with the highest expected impact on reaching $10,000/month, judged by:

1. Does it attack the current bottleneck? (If not, it is almost certainly the wrong action.)
2. Can it be done at $0?
3. Does it produce evidence we do not already have?
4. How many founder-minutes does it cost, against a 6–10 hr/week budget?

State the action in one line, name the owning agent, then **execute it** — do not ask permission for
anything inside Level 2 autonomy (research, analysis, writing, code, workspace updates).

Stop and ask only if the action would spend money, send outbound communication, create an account,
or commit the business to something irreversible. In that case write it to `business/APPROVALS.md`
and present it with the cost of delay.

When finished, update the workspace files you touched and state what changed and what it proved.
